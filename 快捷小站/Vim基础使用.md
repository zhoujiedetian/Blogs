# Vim 基础使用

Vim 是一个**模式编辑器**：大多数时间用于阅读、移动和修改文本，只有需要输入新内容时才进入插入模式。它的核心思路是把按键当作可组合的命令：`d`（删除）配合 `w`（一个单词）就是 `dw`（删除一个单词）。

> 参考：[Missing Semester - Editors (Vim)](https://missing.csail.mit.edu/2020/editors/)

## 打开与退出

```bash
vim 文件名        # 打开或新建文件
vimtutor          # 官方交互式教程，推荐从这里开始
```

以下命令均在普通模式输入；先按 `Esc` 可从任意模式回到普通模式。

| 命令 | 作用 |
| --- | --- |
| `:w` | 保存文件 |
| `:q` | 退出当前窗口 |
| `:wq` / `:x` | 保存并退出 |
| `:q!` | 不保存，强制退出 |
| `:e 文件名` | 打开文件 |
| `:help 主题` | 查看帮助，如 `:help dw` |

## 常用模式

| 模式 | 进入方式 | 用途 |
| --- | --- | --- |
| 普通模式 | `Esc` | 移动、删除、复制和执行命令；启动后的默认模式 |
| 插入模式 | `i` | 在光标前输入文本 |
| 插入模式 | `a` | 在光标后输入文本 |
| 插入模式 | `o` / `O` | 在下方 / 上方新开一行并输入 |
| 可视模式 | `v` / `V` | 按字符 / 整行选择文本 |
| 块可视模式 | `Ctrl-v` | 矩形选择，可用于列编辑 |
| 命令行模式 | `:` | 保存、退出、查找替换等 Ex 命令 |

## 移动：把光标送到目标位置

| 命令                  | 作用                              |
| ------------------- | ------------------------------- |
| `h` `j` `k` `l`     | 左、下、上、右                         |
| `w` / `b` / `e`     | 下个单词开头 / 上个单词开头 / 当前或下个单词结尾     |
| `0` / `^` / `$`     | 行首 / 第一个非空白字符 / 行尾              |
| `gg` / `G`          | 文件开头 / 文件结尾                     |
| `数字G`               | 跳转到指定行，如 `42G`                  |
| `Ctrl-u` / `Ctrl-d` | 向上 / 向下翻半页                      |
| `f字符` / `F字符`       | 在当前行向前 / 向后查找字符；`;` 重复，`,` 反向重复 |
| `/关键词`              | 向下搜索；`n` 下一个，`N` 上一个            |

## 编辑：动词 + 移动命令

普通模式中的编辑命令可以和移动命令组合。先记住 `d`（删除）、`c`（修改）和 `y`（复制），再把移动命令当成操作范围。

| 命令                 | 作用                  |
| ------------------ | ------------------- |
| `x`                | 删除当前字符              |
| `dw` / `d$` / `d0` | 删除一个单词 / 到行尾 / 到行首  |
| `cw`               | 修改一个单词，删除后进入插入模式    |
| `dd` / `yy`        | 删除 / 复制整行           |
| `p` / `P`          | 在光标后 / 前粘贴          |
| `u` / `Ctrl-r`     | 撤销 / 重做             |
| `.`                | 重复上一次修改             |
| `3dd` / `5w`       | 删除 3 行 / 向前移动 5 个单词 |

文本对象能让范围更精确：`ci(` 修改圆括号内内容，`di[` 删除方括号内内容，`da'` 删除包含单引号在内的整段内容。`i` 表示“内部”，`a` 表示“连同边界”。

## 选择、搜索与替换

1. 按 `v` 进入可视模式，用移动命令扩展选区；按 `d` 删除、`y` 复制、`c` 修改。
2. `:%s/旧文本/新文本/g` 将当前文件所有匹配替换为新文本。
3. `:%s/旧文本/新文本/gc` 会在每一处替换前确认。

## 多文件与分屏

Vim 将打开的文件称为 buffer（缓冲区），窗口只是 buffer 的一个视图。

| 命令 | 作用 |
| --- | --- |
| `:ls` | 列出已打开的 buffer |
| `:b 数字` | 切换到对应 buffer |
| `:sp 文件名` | 水平分屏打开文件 |
| `:vsp 文件名` | 垂直分屏打开文件 |
| `Ctrl-w w` | 在窗口之间切换 |

## 建议的学习路径

1. 在终端运行一次 `vimtutor`，约需半小时到一小时。
2. 先只练习 `Esc`、`i`、`:wq`、`hjkl`、`w`、`b`、`dd`、`yy`、`p`、`u` 和 `/`。
3. 日常编辑时，发现某个操作反复使用鼠标或方向键，就搜索是否有对应的 Vim 命令。
4. 等基础动作形成肌肉记忆后，再考虑配置 `~/.vimrc`、插件或在 VS Code 中启用 Vim 模拟。

不要试图一口气记住全部命令；先把“回到普通模式 → 移动到目标 → 用编辑命令作用于目标”这一流程练熟即可。
